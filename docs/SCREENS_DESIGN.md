# تصميم الشاشات — SCREENS_DESIGN

## 1. مبادئ مأخوذة من بساطة الدفتر اليومي

1. **الرصيد أولاً:** أكبر رقم في أي شاشة هو الرصيد.
2. **اتجاهان بلونين:** أخضر = دخل/أخذت، أحمر = خرج/أعطيت. لا يُعتمد على اللون وحده؛ يرافقه سهم ونص.
3. **الكاميرا على بُعد ضغطة واحدة** من أي مكان (زر عائم).
4. **التاريخ الافتراضي "الآن"**، والحقول الاختيارية مطوية.
5. **الشاشة تتغير حسب الدور:** الفني يرى عهدته وأزرار التسجيل؛ المعتمد يرى صندوق الاعتمادات أولاً.

الهوية البصرية خاصة بنا بالكامل؛ لا نستخدم شيئاً من هوية التطبيق المرجعي. الألوان والخطوط والمكونات في [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md)، والنموذج التفاعلي في `prototype/smart-cash.html`.

## 2. خريطة الشاشات

```
تسجيل الدخول ← (MFA للأدوار الحساسة) ← اختيار الشركة إن تعددت
│
├─ الرئيسية (حسب الدور)
│   ├─ 📷 تصوير فاتورة            ← الكاميرا ← مراجعة الاستخراج ← اختيار العهدة ← إرسال
│   ├─ ➖ إضافة مصروف (بدون فاتورة / فاتورة لاحقاً)
│   ├─ ➕ تسجيل إيراد
│   ├─ 💼 عهدي / إضافة عهدة
│   ├─ ✅ الاعتمادات (عدد المعلّق)
│   ├─ 🔍 مراجعة الفواتير (للمحاسب: التنبيهات)
│   ├─ 📁 الحافظات
│   ├─ 📒 دفتر الحسابات (عملاء / موردون)
│   └─ 📊 التقارير
│
├─ العهدة ← الرصيد + الحركات + الحافظة الحالية (x/30) + طلب تعزيز + طلب تسوية
├─ الدفتر ← قائمة الأشخاص ← شخص ← [أعطيت] [أخذت] [تذكير] [كشف PDF]
├─ صندوق الاعتمادات ← طلب ← (صورة الفاتورة + الحقول + التنبيهات + السجل) ← [اعتماد] [إعادة] [رفض]
├─ لوحة التحكم المالية (ويب/لوحي)
└─ الإعدادات ← اللغة، الوضع الليلي، القفل بالبصمة، الأجهزة
    └─ (مدير النظام) المستخدمون، الهيكل، الأدوار، المسارات، حدود الاعتماد، سجل التدقيق
```

### 3.6 لوحة التحكم المالية (ويب)

صف بطاقات: العهد المفتوحة · المصروف هذا الشهر · المعتمد · المعلّق · المرفوض · عهد متأخرة التسوية.
ثم: رسم المصروفات الشهرية · توزيع حسب المشروع · حسب التصنيف · جدول التنبيهات الذكية (تكرار، ارتفاع سعر، عهدة تقترب من النفاد، مستندات ناقصة) · أكثر الموظفين صرفاً.

## 4. اللغة والاتجاه والمظهر

- العربية افتراضياً (RTL) والإنجليزية (LTR)، التبديل فوري.
- الأرقام: لاتينية افتراضياً في المبالغ لسهولة المطابقة مع الفواتير، مع خيار الأرقام الهندية.
- الوضع الليلي والنهاري يتبع الجهاز أو يُختار يدوياً.
- خط عربي واضح للأرقام (مثل IBM Plex Sans Arabic).

## 5. النموذج التفاعلي

✅ منفّذ: الترحيب، الرئيسية، التصوير (فاتورة ضريبية وعادية)، القراءة، مراجعة الاستخراج، الاعتمادات وتفاصيل الطلب، الحافظة والإغلاق المبكر، الدفتر وصفحة الشخص، الإعدادات. الخطوة التالية: تجربته مع فني ومحاسب حقيقيين وجمع الملاحظات.
